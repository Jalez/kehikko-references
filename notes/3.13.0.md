- **Copy several references at once.** With two or more rows selected, "Copy N references" puts one line per reference on the clipboard, in the order the list shows them, each linked with its title. Its small menu copies just the ids instead, ready to hand to an agent. Cmd+C does the same while rows are selected.
- **One menu at the end of each row.** "⋯" holds "Open in your browser", which opens the issue or merge request outside the app, "Copy reference", and the latest activity by somebody else, which used to be a bell. A dot on "⋯" says there is such activity. Clicking the row still shows it in the app.
- **The state is a coloured icon.** Open, draft, merged and closed each have their own icon beside the pipeline's, and hovering or focusing it says the state in words, such as "Merge request · open" or "Issue · closed by !4019".
