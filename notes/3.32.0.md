Kind: feature

- **An open issue says what is closing it.** When a merge or pull request that closes an open issue has not merged yet, the issue's relation cell reads "Closing in !56 (open)", or "(draft)" while the change is a draft. With several, the first shows with "+2", and hover or a screen reader gets all of them. Once the change merges, the cell says "Closed by !56".
- **Order of the relations.** Closes, Closed by, Closing in, Part of, Has contributions from.
- **Needs a current app.** The change's state comes with the issue from this app version on; an older app still gets it for any change that is on the same list.
