- **Work that is part of an issue shows with it.** A merge request or pull request whose description says it is part of an issue the epic names is now listed under This epic beside that issue, and with a part picked that lists the issue. It used to be missing from the epic's list.
- **Says what it is part of.** Such a row reads "part of" and the issue it belongs to, and the issue's row reads "has contributions from" and the work on it, beside the title and in the row's tooltip.
- **Part of an issue is not done.** When work that is only part of an issue merges, the issue stays as its tracker says: an open issue stays open, and it is not counted as closed by a merge.
