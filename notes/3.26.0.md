- **Last activity names the file and line.** With an up-to-date Kehikot, a comment on a change says where it was ("commented on line 42 of api.ts"), a push says how many commits, and a review says whether it approved or asked for changes.
- **Each reviewer's open threads and review time.** The review tooltip counts the threads each reviewer opened that are still unresolved, and says when they approved or asked for changes, so a review of an older version is flagged correctly.
